# AI Assist

AI Assist puts an AI chat assistant inside Salesforce, on record pages and in the utility bar. It is built as a package so it can be installed, upgraded and reused like any other utility, and it is designed so that **personal data is masked before anything leaves the org**, **every user is held to a usage policy**, and **every reply can be traced back to what produced it**.
